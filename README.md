# MacRight

使用 Swift 重写 MacNewFile 的 macOS Finder 右键工具。规划支持新建常用文件、复制完整路径和在目录打开终端；Office 文件直接复制内置空白模板。

**当前状态：方案与资源准备阶段，尚无 Swift 实现或可安装版本。**

- [技术方案](docs/02-技术方案.md)
- [任务清单](docs/03-任务清单.md)
- [资源来源与校验](Resources/README.md)

应用图标复用现有 MacNewFile 的 AppIcon。Finder 仅提供右键入口。
