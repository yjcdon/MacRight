## C. Swift 实现

- [x] C-01（F-01）实现上下文解析与菜单，覆盖单选、多选和空白处，工具栏回调不提供菜单。
- [x] C-02（F-02）实现文本、Markdown、Word、Excel、PowerPoint 五类文件的类型与固定资源映射，Office 直接复制已入库模板，文本和 Markdown 写空内容。
- [x] C-03（F-02）实现统一命名、非覆盖写入、仅名称冲突重试，以及创建后的 Finder 定位。
- [x] C-04（F-03）实现单选、多选和当前目录路径复制，处理剪贴板失败。
- [x] C-05（F-04）实现经过 B-05 验证的 Terminal 调用方式。
- [x] C-06（F-06）实现目录授权、书签生命周期、取消和权限错误反馈。
- [x] C-07（F-01、F-05）实现经过验证的卷监控和扩展独立运行方式。
- [x] C-08（F-05）实现主应用状态页与系统管理入口，关闭应用不关闭扩展，不自动加入登录项。
- [x] C-09（全部）接入简体中文、英文和原 AppIcon，检查各尺寸显示；补充必要的业务方法说明。

## D. 构建、安装与验收

- [x] D-01 提供可重复的构建和本地安装步骤，验证应用及扩展签名和模板打包完整性。
- [ ] D-02 在已授权目录创建文本、Markdown、Word、Excel、PowerPoint 五种文件；Office 输出与内置资源字节一致，并在 WPS 或对应 Office 应用打开，无修复提示。
- [ ] D-03 覆盖命名冲突、快速连点、多进程并发、特殊字符路径，确认不覆盖原文件、不修改模板。
